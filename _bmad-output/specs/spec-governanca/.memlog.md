---
topic: Módulo de governança do portal
goal: Disponibilizar uma página única para leitura e download dos quatro documentos oficiais da FUG
updated: 2026-09-16T13:02
---

- (direction by user) Criar somente a especificação do módulo de Governança nesta etapa; a implementação será feita posteriormente.
- (decision) A implementação futura será iniciada na branch feature/governanca, criada a partir da develop local.
- (capability) CAP-1: o visitante acessa uma página própria de Governança a partir da entrada Governança na página inicial.
- (capability) CAP-2: o visitante identifica e escolhe entre Regimento Interno, Relatório Escola Movimento 2025, Código de Ética e Estatuto.
- (capability) CAP-3: o visitante visualiza cada documento no navegador sem precisar baixá-lo antes para iniciar a leitura.
- (capability) CAP-4: o visitante baixa cada documento individualmente e recebe o PDF correspondente.
- (capability) CAP-5: a página é utilizável por teclado, leitor de tela e viewport móvel.
- (constraint) Os quatro PDFs oficiais são a fonte de verdade; o portal não deve transcrever, resumir, editar ou recompor o conteúdo.
- (constraint) A entrega é uma única página de Governança, sem criar fluxos separados para cada documento.
- (constraint) Cada ação de download deve apontar para o arquivo oficial do documento selecionado, sem gerar PDF no navegador.
- (assumption) Os quatro arquivos fornecidos pelo usuário são as versões oficiais que devem ser publicadas.
- (assumption) Os arquivos serão publicados no repositório em downloads/ com nomes de URL normalizados, preservando os bytes originais.
- (question) A visualização deve ficar embutida na página ou abrir o visualizador nativo do navegador em nova aba?
- (event) Pass 1 de coerência aprovado: SPEC-governanca contém cinco capacidades com intent e success, constraints de design, non-goals, success signal, assumptions e open questions.
- (event) Pass 2 de preservação aprovado: a branch solicitada, a página única, os quatro PDFs, a visualização no navegador e o download individual estão registrados na SPEC ou no companion documentos-oficiais.md.
- (event) Spec de Governança finalizada para implementação posterior; nenhum código ou PDF foi alterado nesta etapa.
