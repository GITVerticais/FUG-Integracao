updated: 2026-09-15T10:12
---

- (direction) Usuario pediu avaliacao framework x web puro antes de implementar a Estrutura Organizacional.
- (decision) Web puro, sem framework SPA/SSG: 267 registros estaticos, sem autenticacao, estado ou tempo real; portal de transparencia exige HTML indexavel e acessivel sem JS.
- (decision) Tailwind compilado via CLI substitui o CDN; o CSS gerado fica versionado para que quem so edita conteudo nao precise de Node.
- (decision) Migracao futura para 11ty ou Astro fica barata se os dados ficarem em data/*.json e o HTML for semantico desde agora.
- (capability) CAP-1 build de CSS Tailwind compilado e versionado, sem cdn.tailwindcss.com.
- (capability) CAP-2 pipeline deterministico XLSX/PDF para data/*.json versionado.
- (capability) CAP-3 normalizacao documentada dos dados de origem: caixa, espacos, caracteres invisiveis e typos.
- (capability) CAP-4 shell de pagina com navegacao por secoes funcional sem JavaScript.
- (capability) CAP-5 gerador que injeta as tabelas como HTML estatico entre marcadores no arquivo publicado.
- (constraint) O pipeline transcreve e normaliza formato; nunca calcula, concilia ou infere valores.
- (constraint) Os .xlsx e .pdf oficiais ficam versionados em downloads/ como fonte de verdade.
- (constraint) As tabelas devem existir no HTML servido, nao montadas por JS no cliente.
- (constraint) Todo conteudo publicado em pt-br.
- (assumption) Ano de referencia 2025, conforme o organograma oficial Anexo II FUG 2025.
- (assumption) Deploy e hospedagem estatica; o build roda local ou em CI, nunca no servidor.
- (question) O index.html existente migra para o CSS compilado nesta spec ou em spec separada?
- (event) Implementacao parcial na branch feature/estrutura-organizacional: tools/xlsx_to_json.py, tools/pdf_to_json.py, package.json, tailwind.config.js, assets/css/input.css.
